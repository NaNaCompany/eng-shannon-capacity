シャノン通信路容量計算機

帯域幅と受信 SNR から、帯域制限 AWGN 通信路のシャノン容量を計算します。 入力単位を選択し、指定された条件内で 1 つの値を計算します。

入力値

SI 単位への換算後に 0 より大きい値

負・0・正の値

計算はこのブラウザー内で行います。1.2e-3 などの指数表記に対応しています。桁区切り文字は使わないでください。

計算結果

理論通信路容量 C

—

値を入力し「計算する」を押してください。

公式

C = B log₂(1 + 10^(SNR_dB/10))

適用条件

平均電力制約を持つ帯域制限された加法性白色ガウス雑音通信路を仮定します。同じ通信路帯域内の受信信号電力と雑音電力の比を dB で入力してください。結果は理論的な符号化限界です。プロトコルの付加情報、有限符号長、フェージング、干渉は考慮しません。異なる帯域幅で測った SNR は使用前に補正が必要です。

表示値は浮動小数点数による近似値です。設計安全率や、入力されていない誤差要因は計算しません。
