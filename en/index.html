Shannon Channel Capacity Calculator

Calculate the Shannon capacity of a band-limited AWGN channel from bandwidth and received SNR. Choose input units and calculate one value within the stated conditions.

Inputs

Greater than zero after conversion to SI

Negative, zero or positive

Calculations run in this browser. Scientific notation such as 1.2e-3 is supported. Do not group thousands.

Result

Theoretical channel capacity C

—

Enter values and select Calculate.

FORMULA

C = B log₂(1 + 10^(SNR_dB/10))

Assumptions

Required: a band-limited additive white Gaussian noise channel under an average-power constraint. Enter the received signal-power to noise-power ratio within that same channel bandwidth in dB. The result is a theoretical coding limit. Excluded: protocol overhead, finite coding length, fading and interference. An SNR measured over a different bandwidth must be adjusted before use.

Displayed values are floating-point approximations. Design safety factors and unprovided error contributions are not calculated.
